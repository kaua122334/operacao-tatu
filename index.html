Clique na tela para começar, escolha o mapa (Vale das Chamas) e depois seu personagem (Tatu ou Brasa). Segure o botão esquerdo do mouse para atirar e mover o cursor para mirar: o soldado vira para o lado dele e atira para cima se o cursor estiver bem acima. Pegue a caixa H para a metralhadora e a G para mais granadas.

Dica: gire o celular para a horizontal para jogar em tela cheia.
